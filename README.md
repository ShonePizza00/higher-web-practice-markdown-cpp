# MarkdownToHTML Converter

## Структура проекта

Проект разделён на две части:

- Приложение - `main.cpp`
- Библиотека конвертера - подпроект `converter`

## Сборка и запуск в Linux

Команды запускайте из корня проекта.

- `sh build.sh` сконфигурировать и собрать проект в `build/`
- `sh run.sh` запустить заранее собранное `examples/input.md`
- `sh build_and_run.sh` собрать проект и запустить пример
- `sh run_tests.sh` собрать проект и прогнать CTest, включая проверки CLI и фикстур
